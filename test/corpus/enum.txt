// **`__enum` is a struct whose state is declared by its cases**, new in Mojo
// 1.2 (`27eb5cf475`). Its head is the struct head (`parseStructStmt` parses
// both, `ParserStmts.cpp:5156-5175` at `mojo/v1.2.0`). A case is
// `"case" name ["(" types ")"]` (`parseEnumCaseStmt`, `ParserStmts.cpp:5213`),
// a simple statement, so `;` joins two and a one-line body holds one. The
// shapes are the ones `decls/enum_decls.mojo` exercises.

================================================================================
Cases with and without a payload, beside methods
================================================================================

__enum Color(Copyable):
    """Colours."""
    case red
    case rgb(Int, Int, Int)
    comptime N = 3

    def is_red(self) -> Bool:
        match self:
            case .red:
                return True
            case _:
                return False
