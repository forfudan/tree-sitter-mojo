// **t-string 的身體要數大括號的層數**，所以它歸外部掃描器
// （`src/scanner.c` 的 `scan_t_string`，照 Mojo 的 `Lexer.cpp:528-915` 搬的）。
// 這幾格釘的是正則數不出來的那幾種：插值裏同一種引號、t-string 套 t-string、
// 括號裏換行之後的那一個、相鄰拼接，以及三引號。
//
// Warning: **這一族不能只看紅綠。** `t"a{"b"}"` 被內部詞法器收成兩個普通字串
// （`t"a{` ＋ `b"}"`）的時候它們自己拼成一個 `concatenated_string`，**一個 ERROR
// 都不出**。所以每一格的期望樹裏都要看見 `t_string` 那個節點名。
//
// Warning: **`tree-sitter test -u` 會把這一段刪掉**，而且不只刪 `--file-name` 點到的
// 那個檔——它把讀過的每一個語料檔整份重寫。要用 `-u` 就先跑、後補註釋。
