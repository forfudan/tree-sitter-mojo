// **`if case`, `elif case` and `while case` test a pattern**, new in Mojo 1.2
// (`8e6cfa75f8`, `8f0c263cd1`). The production is the comment above
// `parseWhileStmt` (`ParserStmts.cpp:1531-1532` at `mojo/v1.2.0`):
//
//     "case" pattern "=" assignment_expression
//
// The pattern is the same expression list a `case_clause` takes, so the
// `case_condition` node holds the same kinds of patterns. There is no guard:
// the `=` ends the pattern.

================================================================================

================================================================================

def f(v: Optional[Int]):
    if case .Some(x) = v:
        print(x)
    elif case .None = v:
        pass
    else:
        pass
