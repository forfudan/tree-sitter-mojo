// **`var` 與 `ref` 是前綴運算符，與 `not`／`-`／`await` 同一族**
// （`ParserExprs.cpp:510-511` 的 `switch`，優先級 `kVarRefPat`）。所以它們出現得了
// 任何一個表達式的位置，前兩格釘的就是語料裏真有的那兩處：元組裏、關鍵字實參的值上。
//
// 第三格是反面：**語句開頭那個 `var` 仍然歸宣告**（樹上是 `assignment`，不是一個
// `binding_expression` 的表達式語句）。`binding_pattern` 那個 `prec(-1)` 管的是這條。
//
// Warning: **`tree-sitter test -u` 會把這一段刪掉**，而且不只刪 `--file-name` 點到的
// 那個檔。要用 `-u` 就先跑、後補註釋。
